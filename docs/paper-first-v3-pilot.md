# Paper-first workflow validation

Private trial reports and operational timings are retained privately. This page
does not claim a real production acceptance or present a synthetic example as one.

For a fresh isolated calibration, follow [paper-first v3](paper-first-v3.md).
Validate each source-bound paragraph, figure, condition and independent review;
retain partial and rejected outcomes honestly. Exercise the bounded repair path.
Verify compact checkpoints by restoring into an empty directory, comparing file
hashes and confirming no new jobs were admitted. Keep private receipts and actual
report files outside this public repository. Offline regressions are under
`tests/test_paper_first.py` and `tests/test_compact_checkpoint.py`.
