# Public configuration examples

These files illustrate the reusable research workflow; they are not a restored
personal profile or evidence of an installed production schedule. Topic vocabulary
demonstrates the supported ranking features. Choose your own keywords, quotas and
source budgets in a separate private runtime root.

The delivery example uses UTC and illustrative times. External delivery is
disabled. Full-quality source enforcement preserves delivery configuration, so
it cannot reactivate disabled channels or overwrite your timezone and schedule.
Enable a transport only after configuring and verifying its destination.

Store actual preferences, non-secret configuration and personal reports in a
separate private repository. Credentials always stay in environment variables or
external secret storage. Do not copy personal Site source or runtime receipts
into this public repository. See [repository separation](../docs/github-persistence.md).
